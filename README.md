# Claude Code Director Demos

A small static site that walks directors through four short Claude Code "vibe coding" recipes — each one a tiny project a director can build for themselves to support their own workflow.

The four demos:

1. **Daily Brief** — curated morning read driven by `interests.md` + `sources.md`.
2. **Personal Secretary** — today's plan, pulled from Microsoft 365.
3. **Stakeholder Management** — markdown-driven relationship dashboard.
4. **Team Management** — 1:1 prep + status rollup from per-report markdown notes.

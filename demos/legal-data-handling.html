🔒 Working Safely with Client Data

Read this before you paste a single document. Not optional.

These workflows put real client documents in front of an AI. Done right, that's a powerful first-pass tool. Done carelessly, it can waive privilege, leak client data, or put a wrong fact into a filing. Five rules keep it safe.

1. Use a commercial, no-training tier

Use Claude only on a tier that does not train on your inputs — Enterprise, Team, or the API. Consumer tiers may use what you type to train models. For client work, that distinction is not a preference; it's the line between a private tool and an external disclosure. If you're not certain which tier you're on, stop and confirm before uploading anything.

2. Keep client data inside approved walls

Work only inside approved, access-controlled workspaces. Don't paste raw client identifiers — names, account numbers, SSNs — into anything outside those walls, and don't email documents to a personal account to "make it easier." If a workflow needs an identifier to be useful, keep the whole job inside the sanctioned environment rather than carving the identifier out into the open.

3. Privilege is not automatic

Treat AI exchanges the way you treat any communication that could be discoverable. In United States v. Heppner (S.D.N.Y., 2026), a federal court found that a party's exchanges with a consumer-tier AI carried no attorney-client privilege — the conversation was treated as a disclosure to a third party. The protections you rely on depend on the tier and how the tool is used. Assume nothing; keep privileged work on an approved, no-training tier and document that you did.

4. You're the attorney; Claude is the first pass

There is a human in the loop at every decision point — that's you. Claude drafts, summarizes, and organizes; it does not decide. Verify every citation, date, dollar figure, and case reference against the source document before you rely on it. A digest that says "(p. 14)" is an invitation to check page 14, not a substitute for checking it. Claude is a fast first reader, never the final word.

5. Protect the originals

Keep source files read-only, and back up the folder before any organize run. The organize workflow is built to copy, never move — but a backup is cheap insurance, and the original file layout can itself be evidence. Never let a tool be the only copy of something you can't recreate.

The five rules, in one breath

  • No-training tier only — Enterprise, Team, or API.
  • Client data stays inside approved, access-controlled walls.
  • Privilege isn't automatic — keep privileged work off consumer tiers.
  • Verify every fact and citation against the source. You decide.
  • Originals stay read-only; back up before organizing.

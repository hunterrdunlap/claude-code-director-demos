✍️ Draft from Case File

Built from 📁 Files & commands 🤝 Sub-agents 🧠 Persistent memory

What you'll do

Take a case file you've already organized and have Claude draft work-product from it — a chronology, an issue or dispute summary, a demand-letter draft. The trick: Claude works from the index the organize step built (the manifest and timeline), not by re-reading every PDF. Every factual statement in the draft cites the source document it came from, so you can check it. This is where organizing pays off.

organized/ index → drafts/chronology.md, every line citing a source document.

What you'll need

  • Claude Cowork open on an approved, no-training tier (see Working safely with client data)
  • An organized/ folder from the Organize Case File step — with its README.md and TIMELINE.md
  • A sense of what you want drafted (Claude will ask if you don't say)

Step 1 — Open the organized folder in Cowork

Point Cowork at the folder that contains organized/. If there's no organized/ yet, run Organize Case File first — this workflow reads the index that step produces.

Step 2 — Paste this into Cowork

Paste the prompt and tell Claude what to draft. If you leave the document type blank or the ask is unclear, Claude asks one or two questions before drafting rather than guessing.

I have a case file you've already organized into an organized/ folder (with README.md, TIMELINE.md, and numbered subfolders). Draft me a chronology, a dispute summary, or a demand-letter draft — I'll tell you which. If I haven't said, ask me before you start.

Work from the index, not from scratch:
- Start by reading organized/README.md and organized/TIMELINE.md to get the map of the case.
- Then fan out sub-agents in parallel — one per theme the draft needs (for example: payment history, dispute and credit-reporting events, communications, account identifiers). Each one reads only the relevant subfolder's _README.md and the specific documents it points to, and brings back the facts, dates, and short quotes for its theme.
- Assemble the draft into drafts/. After every factual statement, cite the source document by its organized filename, like (03-Disputes-and-Credit-Reporting/2025-02-14 ACDV Response.pdf).
- At the end, list anything I asked about that the file doesn't support.

Rules:
- Every fact must come from a document in organized/. If it's not in the file, don't write it — list it as a gap instead.
- Don't invent dates, quotes, names, or numbers.
- Only write into drafts/; leave organized/ read-only.
- End the draft with: "DRAFT — attorney review required. Verify all facts and citations against the source documents before any use or filing."

If you're not sure what I want drafted, ask me one or two questions first.

What Cowork does

Because the index already says where everything is, Claude doesn't re-read the whole file. It reads the map, then sends a sub-agent after each theme the draft needs — they go straight to the right documents, in parallel, and bring back cited facts.

Reading the index:

  ✓ organized/TIMELINE.md (38 dated events)
Fanning out sub-agents by theme, in parallel:

  ├─ dispute & credit-reporting .... 14 facts
  ├─ communications ................ 7 facts

Assembling drafts/chronology.md — every line cites a source document
⚠ 2 requested points unsupported by the file — listed as gaps

What you get

A draft you can build on — sourced line by line, with an honest list of what the file doesn't support so you know where the holes are.

What drafts/chronology.md looks like

Every event traces to a document in organized/; gaps are called out, not glossed over:

# Chronology — J. Borrower v. Acme Servicing

2019-06-12  Loan originated; promissory note signed.
            (01-Loan-Origination/2019-06-12 Promissory Note.pdf)
2024-08-01  Forbearance approved through 2024-11-01.
            (02-Servicing-and-Payments/2024-08-01 Forbearance Approval.pdf)
2024-12-03  First late-payment mark reported to the bureaus.
            (03-Disputes-and-Credit-Reporting/2024-12-03 Tradeline Update.pdf)
2025-01-20  Borrower disputes the mark in writing.
            (04-Correspondence/Outgoing/2025-01-20 Dispute Letter.pdf)
2025-02-14  ACDV response verifies the disputed mark as accurate.
            (03-Disputes-and-Credit-Reporting/2025-02-14 ACDV Response.pdf)

## Gaps (not supported by the file)
- No record of the borrower's alleged Nov 2024 phone call. [requested, not found]
- Payment history missing Sep–Nov 2024 — cannot confirm on-time status.

---
DRAFT — attorney review required. Verify all facts and citations against the
source documents before any use or filing.

Why it matters

This is the difference between "Claude wrote something" and "Claude assembled a draft I can stand behind." It's built so every line should point to a document and gaps are called out explicitly — so your review focuses on confirming citations rather than hunting for invented facts. And because it reads the index instead of the raw file, drafting stays fast even on a case with hundreds of documents. Organize once; draft from it again and again. One caution: the index summarizes each document — a very long file may have been read only in part — so pull the full source for anything a draft leans on heavily.

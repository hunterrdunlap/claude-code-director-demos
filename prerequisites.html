Before you start

Three things. That's it.

1. An Anthropic account

Request access through Nelnet's service catalog. Pick the request that matches you:

  • Non-developer access — for everyone using Claude as part of their day-to-day work.
  • Developer access — if you're writing code or building integrations.

2. The Claude desktop app

Once your account is approved, install the Claude desktop app and sign in. That's the whole setup — no terminal, no npm, no Node. Everything in this tour runs from the desktop app.

3. Git

Install Git from the Nelnet Software Center on your laptop. A few of the demos use it under the hood; you don't need to know any Git commands yourself.

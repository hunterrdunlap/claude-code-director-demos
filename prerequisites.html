Before you start

Two things. That's it.

1. An Anthropic account

Request access through Nelnet's service catalog. Pick the request that matches you:

  • Non-developer access — for everyone using Claude as part of their day-to-day work.
  • Developer access — if you're writing code or building integrations.

2. The Claude desktop app

Once your account is approved, install the Claude desktop app from the software portal and sign in. That's the whole setup — no terminal, no npm, no Node. Everything in this tour runs from the desktop app, and Git now comes bundled in the download, so there's nothing else to install.

Already have Claude installed? If you set it up before Claude Cowork was included in the download, uninstall and reinstall from the software portal and you should be all set. Installs occasionally hit tricky edge cases — the Nelnet Help Desk is there to help with those.
